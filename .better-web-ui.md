## Design Context

### Users
ETHGlobal Mumbai judges and the person giving a two-minute demo. They need to see a frame transaction the public mempool refuses and the alt mempool admits, plus an honest Anon-RPC read path. Secondary audience is a developer reading the repo after the hackathon.

### Brand Personality
Calm, specific, slightly dry. Three words: warm, strict, honest. The interface should feel like an ops tool a person trusts with a key, not a campaign site.

### Aesthetic Direction
PostHog product UI via `.cursor/skills/posthog-ui-skills`: olive-grey page (`#f0f0eb`), white panels, heat-orange primary (`#f54e00`), separate red for danger (`#db3707`), Inter (self-hosted, no CDN), 4px spacing grid, 3px radii, 1px borders, focus ring `#5e6ad2`. Light mode for the demo. Do not copy the PostHog logo, hedgehog, RoundHog, or Squeak. Do not ship a font CDN or a tracker.

### Implementation Defaults
Vite + React 19. Tokens live in `apps/web/src/tokens.css` (imported by `index.css`). shadcn/Radix primitives are allowed for shell chrome; prefer semantic CSS classes for product surfaces. Chain code lives in `packages/core`.

### Design Principles
- One orange primary action per screen. Danger stays `#db3707`, never the brand orange.
- Dense product chrome (13–14px body, regular weight). Marketing brand name stays hero-scale.
- Hover list/secondary actions use `#e38b20` wash. Disabled: `opacity: 0.5` + `not-allowed`.
- No entrance animations unless explicitly requested. Prefer compositor-only motion under 200ms.
- The ops log shows method, route, and verdict. It does not show addresses, payloads, or keys.
- Say what Anon-RPC does not do. The worker sees request bodies. The reference worker does not unlink IP.
